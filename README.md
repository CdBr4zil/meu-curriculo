# 💼 Portfólio — Caio Dias

Site de portfólio pessoal desenvolvido com **HTML5**, **CSS3** e boas práticas de **SEO on-page** e **acessibilidade**. Apresenta minha trajetória, habilidades técnicas e projetos desenvolvidos.

🔗 **[Acesse o portfólio](https://cdbr4zil.github.io/meu-curriculo/)**

---

## 🚀 Tecnologias

- **HTML5** — estrutura semântica e acessível
- **CSS3** — layout responsivo com Flexbox e variáveis CSS
- **Mobile First** — desenvolvido prioritariamente para dispositivos móveis
- **SEO on-page** — meta tags, Open Graph e título otimizado
- **Fonte variável** — RobotoMono via `@font-face`

---

## 📋 Seções

| Seção | Descrição |
|-------|-----------|
| **Hero** | Apresentação com foto, botões de projetos e download do CV |
| **Sobre** | Cards de Formação, Experiência e Cursos/Idiomas |
| **Habilidades** | Tags organizadas por categoria (Linguagens, Frontend, Backend...) |
| **Projetos** | Cards com links para os repositórios no GitHub |
| **Contato** | Rodapé com links para LinkedIn e GitHub |

---

## ✨ Funcionalidades

- Layout **100% responsivo** (mobile, tablet e desktop)
- Menu hambúrguer funcional via **CSS puro** (sem JavaScript)
- Animação flutuante na foto do hero (`@keyframes`)
- Cards de projeto com efeito hover e **parallax de background**
- Tags de habilidades com **hover animado**
- Download direto do currículo em PDF
- Favicon customizado em **SVG**
- Meta tags de **Open Graph** para compartilhamento em redes sociais
